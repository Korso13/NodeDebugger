# README #

NodeDebugger by Tim Korso

### What is this repository for? ###

* Multi-purpose debugger with ImGui UI interface
* Allows node transformations; debugging Spine animations, skins; move and scale tweens testing, assigning debug calls and variables
* Also contains Console tab visible on all mobile devices in debug
* Supports additional UI tabs (modules) with customizable looks and functionality
* Minimal build size impact in Release and Shipping

### Version ###

* Current version 3.3

### How do I get set up? ###

Just drop NodeDebugger in your "common" folder in the base project.
Then use NODEDEBUGGER and otehr shortcut macros to access debugger functions. Read comments in NodeDebugger.h to learn more.
